# 🚀 CareerPilot AI

CareerPilot AI is an AI-assisted internship recommendation and interview preparation system that helps students find suitable internship opportunities based on their resume skills.

## 🎯 Features

- 📄 Resume Upload
- 🔍 Resume Text Extraction
- 🧠 Skill Extraction Agent
- 🎯 Internship Recommendation
- 📊 Internship Match Score
- 🎤 Interview Preparation Agent
- 🚀 Direct Apply Now Links
- 💻 Interactive Streamlit Dashboard

## 🔄 Workflow

Student
↓
Resume Upload
↓
Resume Parsing Agent
↓
Skill Extraction Agent
↓
Internship Recommendation
↓
Match Score Calculation
↓
Interview Preparation Agent
↓
Apply Now

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- PyMuPDF
- CSV Dataset
